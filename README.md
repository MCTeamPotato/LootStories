### LootStories

**LootStories** adds a bit of mystery and lore to your adventures by placing *written books* inside loot chests.

Each book contains a short story generated by **DeepSeek** or **ChatGPT**.

You can also include your own stories by adding `.txt` files to the `config/lootstories/` folder.
Each file name should follow the format:
`StoryNamebyAuthor.txt` — for example: `TheLostMinebyAlex.txt`.

### Dependencies

If you have the **Jsonate** installed, you can configure the loot generation chance for these books. It's not a hard requirement, though.

**Modern UI** is required for this mod, or the texts will be pieces of shit.
